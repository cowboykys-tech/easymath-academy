이지매쓰 원격 설치 준비
========================

이 폴더는 원장님 Windows 노트북을 Mac에서 안전하게 설치·관리하기 위한 준비파일입니다.
Python이나 이지매쓰 프로그램을 미리 설치하지 않아도 됩니다.

준비 조건
---------
1. Windows 10 또는 Windows 11
2. 관리자 권한이 있는 Windows 계정
3. 충전기와 인터넷 연결(Tailscale 원격 연결용)
4. Tailscale 설치 및 로그인

실행 순서
---------
1. https://tailscale.com/download/windows 에서 Tailscale을 설치합니다.
2. Tailscale에 로그인하고 Connected 상태인지 확인합니다.
3. START-REMOTE-SETUP.cmd를 두 번 누릅니다.
4. Windows가 권한을 요청하면 '예'를 누릅니다.
5. 검은 창에 '원격 설치 준비가 완료되었습니다'가 나올 때까지 기다립니다.
6. 바탕화면에 생긴 '이지매쓰-원격준비결과.txt'를 확인합니다.
7. Mac 쪽 담당자에게 '원격 준비 완료'라고 알려줍니다.

중요
----
- Tailscale, Google, Microsoft 또는 Windows 비밀번호를 채팅으로 보내지 마세요.
- 이 준비파일에는 Mac의 공개키만 들어 있습니다. 개인키와 비밀번호는 들어 있지 않습니다.
- OpenSSH 설치파일이 압축 안에 포함되어 있으므로 Windows가 설치파일을 따로 내려받지 않습니다.
- 이전 설치가 4/7에서 멈췄더라도 START-REMOTE-SETUP.cmd를 다시 실행하면 현재 상태를 확인하고 이어서 준비합니다.
- SSH 포트는 준비 패키지를 만든 Mac의 Tailscale 주소에서만 연결되도록 방화벽이 제한됩니다.
- 노트북이 꺼지거나 인터넷이 끊기면 원격 작업을 할 수 없습니다.
- 준비를 취소하려면 REMOVE-REMOTE-ACCESS.cmd를 실행합니다.

Tailscale이 설치되지 않았거나 로그인하지 않은 상태에서는 준비파일이 안내 후 종료됩니다.
설치와 로그인을 마친 뒤 START-REMOTE-SETUP.cmd를 다시 실행하면 됩니다.
