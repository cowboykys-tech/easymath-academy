# 이지매쓰 학원관리 시제품

학원 원장님과 실제 화면을 보며 업무 흐름을 확정하기 위한 데스크톱 중심 시제품이다.

공개 저장소: <https://github.com/cowboykys-tech/easymath-academy>

- 처음 설치를 Codex에 맡길 때: `CODEX_DEPLOY_PROMPT.md`
- 자세한 기능·설치·운영 매뉴얼: `output/pdf/이지매쓰-학원관리-상세-운영매뉴얼.pdf`

## 실행

프로젝트 폴더에서 아래 명령을 실행한다.

```bash
python3 server.py
```

- 원장님 앱: `http://127.0.0.1:49321/`
- 선생님 앱: `http://127.0.0.1:49321/teacher.html`
- 학생 등원 태블릿: `http://127.0.0.1:49321/kiosk.html`

세 화면은 모두 설치형 웹앱(PWA)으로 제공한다.

- 원장님 앱: `이지매쓰 원장님`
- 선생님 앱: `이지매쓰 선생님`
- 등원 기기 앱: `이지매쓰 학생 등원`

각 주소를 지원 브라우저에서 연 뒤 `앱 설치`를 누르면 컴퓨터·태블릿·휴대폰의 홈 화면에 각각 별도 앱처럼 설치할 수 있다. iPhone·iPad는 Safari의 공유 메뉴에서 `홈 화면에 추가`를 선택한다. 실제 외부 설치에는 학원 도메인과 HTTPS가 필요하고, `localhost`는 개발 시험에만 사용할 수 있다.

이지매쓰 PWA는 원장님·선생님·등원 기기의 정보를 한 서버에서 실시간으로 동기화하는 **온라인 전용 앱**이다. 인터넷이 끊기면 운영 데이터를 오래된 캐시로 대신 보여주지 않고 연결 필요 화면을 표시한다. 수업·학생·근태·등원 API와 사진은 서비스 워커 캐시에 저장하지 않는다.

실제 운영 전 원장 비밀번호를 등록한다. 비밀번호 원문은 데이터베이스에 저장되지 않는다.

```bash
python3 server.py set-owner-password
```

외부 HTTPS 프록시 뒤에서 실행할 때는 `ACADEMY_REQUIRE_OWNER_LOGIN=1`과 `ACADEMY_HTTPS=1`을 반드시 설정한다.

카카오 로그인은 Kakao Developers에서 앱과 Redirect URI를 등록한 뒤, 키를 파일에 저장하지 말고 환경 변수로 전달한다.

```bash
KAKAO_REST_API_KEY='로컬에서만 설정' \
KAKAO_REDIRECT_URI='http://127.0.0.1:49321/auth/kakao/callback' \
python3 server.py
```

Client Secret을 사용하는 앱은 `KAKAO_CLIENT_SECRET`도 같은 방식으로 설정한다.

## 현재 기능

- 원장 현황판
- 학생 기본정보·학교·학년·보호자 연락처·주소·등록상태·지도 메모 등록/수정
- 선생님 연락처·주소·학력·전공·경력·고용형태·급여정보·재직상태 등록/수정
- 매일 수업 내용·학생별 관찰·사진 기록
- 학생별 개별 피드백 누적 보기
- 수업별 학생 출석·지각·결석·인정결석·보강 기록과 학생별 출석률 누적 보기
- 선생님이 수업별 학생의 수업태도·집중도·이해도·진도·참여도·과제 수행을 빠르게 선택하고 관찰 메모를 남기는 일일 평가
- 선생님 평가를 바탕으로 원장님이 학부모 메시지 초안을 생성·수정·복사하고 발송 완료를 기록하는 일일 피드백함
- 학생별 학부모 카톡방 연결, 원장 최종 확인 후 전송, 전송 결과 기록과 최근 대화 확인을 위한 송수신기 연결 화면
- 등록된 학생 전화번호 뒤 4자리로 등원하는 태블릿·휴대폰용 설치형 웹앱(PWA), 1회용 기기 연결코드와 기기 권한 해제
- 원장님·선생님·등원 기기를 서로 다른 이름과 아이콘으로 설치하는 온라인 전용 PWA
- 같은 뒤 4자리가 겹치면 학생 이름 목록에서 본인을 선택하고, 2시간 안의 중복 입력은 한 번만 저장하는 등원 처리
- 등원 즉시 학부모 카톡 알림을 시도하고 결과를 누적하며, 학생별 주간·월간 등원 리포트 문안 생성·복사·확인 후 전송
- 주간 학부모 카카오톡 문안 검토·복사·발송완료 표시
- 원장님이 선생님별 요일·출근·퇴근·휴게시간을 등록하는 주간 근무계획
- 카카오 로그인 기반 선생님 전용 출근·퇴근·조퇴·추가근무·날짜별 근무시간 변경 요청 화면
- 선생님 앱 상단의 출퇴근 기록 버튼, 오늘 예정 근무와 요청 상태 팝업
- 원장님 전용 근무 요청 승인/반려와 승인된 확정 기록
- 원장님 직접 결근 확정 기록, 입사일·퇴사일·재직 변동과 개인별 전체 근무 이력 조회
- 로그인한 선생님에게 배정된 수업만 보이는 주간 수업 달력
- 이전 달·다음 달로 이동할 수 있는 선생님별 월간 전체 수업 달력
- 수업별 참여 학생 명단 확인
- 학부모 상담 내용과 후속 연락일 기록
- 월~일 주간 시간표와 반·과목·학생·담당 선생님 등록·수정
- 전체·선생님별·학생별 주간 시간표 전환 조회
- 등록 명단 검색 후 시간표에 담당 선생님과 여러 학생 배정
- 첫 화면에서 미작성 수업·학부모 피드백·근태 승인·상담 후속·주간 카톡 준비 건수를 바로 확인하고 해당 업무로 이동
- 작은 화면에서는 핵심 메뉴 4개와 더보기 메뉴를 사용하고, 주간 시간표의 오늘 요일로 바로 이동

## 주의

학생·반·선생님·수업기록·학생 일일평가·등원·학부모 메시지 초안·상담·주간 피드백·시간표·근무계획·출퇴근 및 조퇴·추가근무 승인 기록은 `data/academy.sqlite3`에 통합 저장된다. 기존 브라우저 `localStorage` 데이터는 서버 데이터가 비어 있는 최초 실행 때 자동 이전된다. 새 수업 사진 원본은 `data/photos`에 저장되고 데이터베이스 기록과 연결된다. 원장 로그인과 API 보호, SQLite·사진 백업 생성 및 검증 기능도 포함한다.

학생 등록 때 학생 전화번호를 필수로 입력하면 그 번호의 뒤 4자리가 등원번호가 된다. 같은 뒤 4자리가 여러 학생에게 있으면 연결된 등원 기기에서 이름 목록을 보여 주고 학생이 본인을 선택한다. 등원 기기는 원장 화면에서 만든 10분 유효·1회용 6자리 코드로만 등록하며, 원장님이 언제든 기기 권한을 해제할 수 있다.

학생 출결, 학생 상태 변경, 선생님 입사·퇴사와 원장님이 확정한 결근도 삭제하지 않고 같은 데이터베이스에 누적한다. Obsidian은 운영 데이터 원본이 아니며 사용법·정책·변경 기록만 보관한다. 학생·학부모·선생님의 개인정보와 실제 운영기록은 Obsidian이나 Git에 복사하지 않는다.

```bash
python3 backup.py create
python3 backup.py verify data/backups/backup-YYYYMMDD-HHMMSS
```

학부모 카카오톡 기능은 설치 장치에 종속되지 않는 연결 규격으로 구현되어 있다. 원장님은 학생마다 정확한 채팅방을 한 번 연결하고, 매번 문안을 검토한 뒤 `확인 후 카톡 전송`을 눌러야 한다. 전송 결과가 불명확하면 자동 재전송하지 않는다. 현재 개인 계정이나 특정 컴퓨터는 연결하지 않았으며, 실제 설치 장소가 정해진 뒤 `ACADEMY_MESSAGING_CONNECTOR_URL` 또는 `ACADEMY_MESSAGING_CONNECTOR_CLI`만 설정한다. 연결 규격과 참조 브리지는 `connectors/`에 있다. 수동 문안 복사 방식도 계속 사용할 수 있다.

일일 학부모 피드백의 `초안 만들기`는 설치 환경에 따라 세 가지 방식을 선택할 수 있다. `ACADEMY_FEEDBACK_AI_PROVIDER=codex`는 그 장치에 로그인된 Codex 계정을 비대화형·임시·읽기 전용 모드로 사용하고, `openai`는 OpenAI Responses API를 사용하며, `template`은 외부 AI 없이 기본 초안을 만든다. 기본값은 아직 사용자 계정과 연결되지 않는 `template`이다. `auto`는 Codex, API, 기본 문안 순으로 안전하게 대체한다.

Codex 인증 파일이나 API 키는 애플리케이션 데이터베이스와 Git에 저장하지 않는다. AI 요청에는 학생 이름, 전화번호와 주소를 넣지 않으며 수업·평가 자료만 전달한다. 생성 결과는 자동 발송하지 않고 반드시 원장님이 확인·수정한다. Codex 실행 모델은 `ACADEMY_CODEX_FEEDBACK_MODEL`, API 모델은 `OPENAI_FEEDBACK_MODEL`로 선택할 수 있다.

OpenAI API 방식을 선택했을 때의 기본 모델은 짧은 학부모 문안 작성에 적합한 저비용 모델 `gpt-6-luna`다. Codex 방식은 설치 장치의 기본 모델을 따르며 필요할 때만 별도로 지정한다.

근무시간 변경 요청은 횟수 제한 없이 날짜별로 보낼 수 있다. 같은 날짜의 앞선 요청이 승인된 뒤에도 다시 변경 요청할 수 있으며, 아직 처리 대기 중인 요청만 중복 등록을 막는다. 현재 근무 기능은 승인된 사실 기록을 급여 계산의 근거로 남기는 단계다. 실제 급여 자동 계산은 월급·시급·수업당 급여, 휴게시간과 조퇴·추가근무 계산 규칙을 확정한 뒤 연결한다.

## Windows 설치본

`deploy/windows/Install-EasyMath.ps1`이 프로그램 복사, 원장 비밀번호 등록, 로그인 시 자동 실행, 매일 22시 30분 자동 백업과 바탕화면 바로가기를 준비한다. Windows 11과 Python 3.11 이상을 기준으로 하며 실제 Windows 노트북에서 최종 설치 시험을 거쳐야 한다.

HTTPS 역방향 프록시 초안은 `deploy/Caddyfile.example`, 비밀값 없는 환경설정 예시는 `.env.example`에 있다. 카카오 키는 Windows DPAPI로 암호화하는 `Set-EasyMathSecrets.ps1`을 통해 등록한다.

## 인계와 유지보수

원장님 Windows 노트북에 프로그램, Codex, Obsidian과 백업 환경을 설치하고 직접 유지보수할 수 있게 넘기는 기준은 `HANDOFF_AND_MAINTENANCE.md`에 정리한다.

Mac에서 원장님 Windows 노트북에 원격으로 설치할 때는 `build_remote_setup.py`로 준비 ZIP을 만든다. Windows에서 Tailscale 로그인 후 ZIP의 `START-REMOTE-SETUP.cmd`를 실행하면, Mac 공개키와 Tailscale 전용 SSH 방화벽 규칙을 등록한다. 비밀번호와 Tailscale 인증키는 패키지나 저장소에 넣지 않는다.
