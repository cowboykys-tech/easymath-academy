# 이지매쓰 학원관리 시제품

학원 원장님과 실제 화면을 보며 업무 흐름을 확정하기 위한 데스크톱 중심 시제품이다.

## 실행

`dist/index.html`을 브라우저로 열거나 정적 웹 서버로 `dist` 폴더를 제공한다.

## 현재 기능

- 원장 현황판
- 학생·반·선생님별 가상 데이터 보기
- 진도코드로 과거 수업 기록 검색
- 과거 기록을 불러와 새 피드백 작성
- 임시저장과 원장검토 제출
- 옵시디언용 Markdown 다운로드

## 주의

현재 데이터는 브라우저의 `localStorage`에만 저장된다. 실제 운영 데이터 입력 전 서버, 데이터베이스, 권한, 자동 백업을 구현해야 한다.
